# Test Plan – Edu-Conecta

## 1. Objetivo
Validar el correcto funcionamiento de las funcionalidades principales de Edu-Conecta relacionadas con autenticación de usuarios, búsqueda y filtrado de cursos, y envío de solicitudes para profesor.

---

## 2. Alcance

Las pruebas contemplan:

- Registro de usuario.
- Login de usuario.
- Búsqueda de cursos disponibles.
- Filtrado de cursos por “1er año”.
- Filtrado de cursos por “2do año”.
- Envío de solicitud para profesor.

Fuera de alcance:

- Performance.
- Seguridad.
- Compatibilidad mobile.
- Integraciones externas.

---

## 3. Tipo de pruebas

- Smoke Testing
- Functional Testing
- UI Validation

---

## 4. Entorno de pruebas

- Ambiente: Producción
- Navegador principal: Google Chrome
- Sistema operativo: Windows 10

---

## 5. Criterios de entrada

- Aplicación desplegada y accesible.
- Funcionalidades principales habilitadas.
- Datos mínimos de prueba disponibles.

---

## 6. Criterios de salida

- Ejecución completa de los casos definidos.
- Registro de bugs encontrados.
- Validación de funcionalidades críticas.

---

## 7. Riesgos

- Datos inconsistentes en cursos.
- Validaciones incompletas en formularios.
- Problemas de actualización de filtros.

---

## 8. Entregables

- Test Cases
- Smoke Checklist
- Bug Reports
- Test Summary
